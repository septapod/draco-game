# Draco Game — Claude Code Instructions

## Project Overview
"Draco" is a fantasy adventure game created by Aza Dixon (Brent's son). This project contains the canonical game bible and supporting materials for all Draco adaptations: tabletop game, video game, book series, video series.

## Key Files
- `DRACO_Game_Bible.md` — Full Markdown game bible (v1.2)
- `PROJECT_STATUS.md` — Current project status and version history
- Google Doc (formatted version): https://docs.google.com/document/d/1U43DoqDfHp86OGgNRhY5iRNt3Rluk5UmFo8U6oimE8E/edit

## Working with This Project
- The Google Doc is the **canonical formatted version** — keep it in sync with the Markdown
- When updating content, update BOTH the Google Doc and `DRACO_Game_Bible.md`
- New lore comes from transcripts of conversations with Aza — interpretation is expected
- The Google Docs MCP tools wipe formatting on content updates, so budget time for re-formatting after changes

## Content Guidelines
- Organize new lore into the existing 18-section structure (or add new sections if needed)
- Maintain the Glossary and Named Dragons appendices
- Track unresolved ideas in Section 18 (Open Questions)
- Attribute the game to Aza Dixon as creator
